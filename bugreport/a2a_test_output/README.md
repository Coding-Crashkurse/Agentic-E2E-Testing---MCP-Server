# a2a test output

Written by the testing agent, not by the author of the MCP server. One folder per ticket id from
`../tickets/`, for example `TICKET-101-coupon-no-discount/`, containing `verdict.md`, a
`reproduce/` folder with the artifacts of the run against the site under test, a `control/` folder
with the artifacts of the run against the control build and, if a structured ticket was executed,
`ticket.json`. The template for `verdict.md` is in `../README.md`, section 6.
